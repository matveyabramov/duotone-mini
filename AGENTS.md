# DUOTONE MINI

DUOTONE MINI is a browser-based dual-voice musical instrument built with Tone.js.

## Core requirements

1. The instrument must contain at least two independent voices:
   - Voice A: polyphonic synthesizer played from the piano keyboard.
   - Voice B: sampler/drum voice played from 8 pads.

2. The finished instrument must support a musical performance/composition suitable for a screencast.

## Technical constraints

- Follow the teacher's Tone.js examples and boilerplate where possible.
- Keep the project simple: HTML, CSS and JavaScript.
- Do not introduce React, TypeScript, frameworks or build tooling unless explicitly requested.
- Prefer Tone.js APIs already demonstrated in the teacher's course examples.
- Preserve the existing Figma design closely.
- Do not invent UI controls that are not present in the approved design.
