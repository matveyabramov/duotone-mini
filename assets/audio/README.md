# Drum recording provenance

These eight files are unchanged WAV recordings from the teacher's [ADC-GID-26-27 tutorial 4 TR-909 folder](https://github.com/ZakharDay/ADC-GID-26-27/tree/main/tutorial_4/roland_tr_909), downloaded on 4 October 2026 for the DUOTONE MINI course project. No other sample pack was downloaded.

All eight recordings are distinct, mono, 44.1 kHz PCM WAVs. Pad names and note metadata are preserved from the approved interface. Perc uses the rimshot and Texture uses the crash cymbal. Playback mappings and sampler root notes are centralized in `drumSamples` in `script.js`; replace a file there to change a pad's sound.
